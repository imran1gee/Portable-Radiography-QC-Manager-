# Portable Radiography QC Manager V2

A standalone macOS application for radiography quality control, equipment performance evaluation, and Excel report generation.

## Download for macOS

**[⬇️ Download Portable Radiography QC Manager V2 (.dmg)](https://github.com/imran1gee/Portable-Radiography-QC-Manager-/releases/download/v1.0.0/Portable.Radiography.QC.Manager.V2.-.Final.dmg)**

Download the DMG, open it, and drag the application into your Applications folder.

**Note:** The application is not Apple-notarized. macOS may require you to approve opening it through System Settings → Privacy & Security.

## Source Code

The repository contains the Python source code for the application, including quality-control calculations, measurement entry, report generation, and the macOS launcher.
